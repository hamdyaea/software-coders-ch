Hamdy Abou El Anein — Contributions au noyau Linux

Je propose des correctifs pour les scripts de développement du noyau Linux : analyse des traces, vérification de Kconfig et recherche de références Git. Les échanges avec les mainteneurs sont publics sur Lore : patchs et revues de Hamdy Abou El Anein.

Sélection mise à jour le 12 novembre 2026. Un avis de revue positif ou une intégration dans une branche de maintenance ne signifie pas une fusion dans le noyau principal.

Détecter les collisions de noms de modules entre tiret et souligné

Kbuild et le chargeur de modules traitent les tirets et les soulignés comme équivalents. Le correctif normalise les noms avant de rechercher les doublons, tout en conservant les chemins d’origine dans les diagnostics.

Étape confirmée : appliqué par Nicolas Schier dans kbuild/linux.git, branche kbuild-next-unstable, avec un tag Fixes: ajouté. Le tag next-20261111 de linux-next contient cette normalisation dans scripts/modules-check.sh.

Suivi de la revue : le 8 novembre 2026, Sasha Levin a signalé un échec de ARCH=arm allmodconfig : ce contrôle détecte deux collisions préexistantes, entre apm-power et apm_power, puis entre test-kprobes et test_kprobes. Le 9 novembre, Nathan Chancellor a annoncé avoir soumis deux correctifs de renommage. Pour la collision apm-power, Dmitry Torokhov a proposé de supprimer le pilote d’entrée obsolète. Le 10 novembre, Nicolas Schier a annoncé l’application de ce correctif dans kbuild-next-unstable (commit 7f705c0a).

Signalement de Sasha Levin · Réponse de Nathan Chancellor et correctifs proposés

Commit kbuild bc348949

Préserver le texte des traces avec decode_stacktrace

Le correctif conserve les espaces, les antislashs et la dernière ligne sans saut de ligne lors de la lecture des traces. Il évite de perdre du texte avant son décodage.

Étape confirmée : ajout annoncé par Andrew Morton dans la branche -mm / mm-nonmm-unstable le 3 novembre 2026, avec un Acked-by de Sasha Levin. Dans le tag next-20261111 de linux-next, la boucle de lecture de decode_stacktrace.sh conserve les espaces, les antislashs et la dernière ligne incomplète.

Patch decode_stacktrace de Hamdy Abou El Anein · Annonce de l’ajout dans la branche -mm

Détecter les symboles Kconfig commençant par un chiffre

La vérification numérique doit porter sur le jeton entier. Des noms comme 64BIT_MISSING restent ainsi des symboles à vérifier au lieu d’être ignorés comme des nombres.

Étape confirmée : avis Reviewed-by de Nathan Chancellor reçu le 6 novembre 2026. Cet avis est une revue positive ; la fusion dans le noyau principal n’est pas confirmée ici.

Patch checkkconfigsymbols et fil de revue de Hamdy Abou El Anein

Vérifier les objets Git utilisés dans les références Fixes

La proposition vérifie qu’un identifiant Git abrégé désigne un commit avant de l’utiliser dans une référence Fixes. La version 2 tient compte des échanges de revue.

Étape documentée : version 2 soumise le 4 novembre 2026 ; aucune fusion mainline n’est affirmée ici.
